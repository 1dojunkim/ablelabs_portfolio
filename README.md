# 논문 기반 액체 핸들링 자동화 타겟 리드 발굴

PubMed 논문 데이터에서 실험실 자동화 장비의 영업 대상 연구실을 발굴하는 파이프라인입니다.
에이블랩스(ABLE Labs) Sales Manager 지원 과제로 작성했습니다.

## 문제

액체 핸들링 자동화 장비의 영업은 인바운드 문의 중심입니다. 그러나 문의하는 곳은 이미
자동화를 검토 중인 연구실이고, 아직 수작업만 하는 연구실은 먼저 찾아가야 만납니다.
누가 피펫팅을 많이 하는지는 직접 물어 알 수 없지만, 논문의 실험 방법에 그 연구실의
수작업이 드러납니다. 이 파이프라인은 그 단서로 영업 대상을 발굴합니다.

## 파이프라인

| 단계 | 스크립트 | 처리 | 결과 |
|---|---|---|---|
| 1 | `01_collect.py` | 실험 7종으로 PubMed 검색·수집 | 논문 10,582건 |
| 2 | `02_normalize.py` | 교신저자·기관 정규화, 이메일 추출 | 논문 8,960건 |
| 3 | `03_labs.py` | 논문을 연구실 단위로 집계 | 연구실 5,796곳 |
| 4 | `04_classify.py` | 초록을 LLM으로 읽어 수작업 강도·외주 여부 판정 | — |
| 5 | `05_rank.py` | 제외 기준 적용, 정렬, 제품 결정 | 리드 1,740곳 |

`04b_merge.py`는 4단계가 중간에 멈췄을 때 캐시만으로 결과를 만드는 보조 스크립트입니다.

## 설계 요점

- **교신저자 기준 집계**: 리드의 단위는 논문이 아니라 연구실이다. 생명과학 논문의
  관례상 마지막 저자가 연구책임자이므로, 마지막 저자가 한국 소속인 논문만 남긴다.
- **LLM 판정**: 키워드 검색으로는 "그 실험을 언급했다"까지만 알 수 있다. RNA-seq을
  했다고 써 있어도 시퀀싱을 외주했으면 액체 핸들링을 직접 하지 않은 것이다. 이 구분은
  초록을 읽어야 가능하므로 LLM으로 판정한다.
- **임의 가중치 없는 선별**: 여러 지표를 점수로 합산하려면 임의 가중치가 필요하고 그
  근거가 없다. 대신 예-아니오로 판단되는 제외 기준(외주·연락처)으로 거르고, 남은 리드를
  수작업 강도순으로 정렬한다.

## 실행

```bash
pip install requests pandas

python 01_collect.py        # PubMed 수집 (수십 분)
python 02_normalize.py      # 정규화
python 03_labs.py           # 연구실 집계

# LLM 판정: ANTHROPIC_API_KEY 또는 GEMINI_API_KEY 중 하나 설정
export GEMINI_API_KEY=...
python 04_classify.py       # 초록 판정 (약 80분)

python 05_rank.py           # 선별·정렬
```

각 단계는 중간 결과를 캐시하므로, 중단되면 다시 실행할 때 이어서 처리합니다.

## 데이터 공개 정책

리드 데이터는 공개된 논문에서 수집했으나 연구자 개인정보(이름·이메일)를 포함하므로,
전체 데이터셋은 이 저장소에 공개하지 않습니다. 방법이 재현 가능함을 보이기 위해
이름·이메일을 마스킹한 상위 20곳 샘플만 `leads_sample_masked.csv`로 포함합니다.
